> 后端逻辑已被 `tests/e2e.journeys.test.js`（130 断言）端到端钉死。本脚本只覆盖**机器测不到**的层：真 doubao LLM 解析、前端状态机交互、真云存储附件、canvas 渲染、鉴权 / 隔离 / 推送。
> 跑法：DevTools 导入 `dist/build/mp-weixin`（或真机扫码体验版），登录态就绪。云函数 parseRecord/saveRecord/reminders 均已部署。
> 每条 = 操作 → 预期。打 ✅/❌，❌ 记现象回贴。**占位名按你库里真实宠物替换执行**（文档用 示例猫/示例狗/示例龟）。

## ⭐ 最高优先：真 LLM 的 Round1 vs Round2 区分（后端 mock 不了，这是头号风险）
- [ ] **A0 同事件 → 单卡多选**：说「给示例猫和示例狗都做了体外驱虫」→ 确认卡应是**一张卡 + 多选 chips 预勾两只**（不是拆成两张）→ 确认落 2 条同内容。
- [ ] **A0' 不同事件 → 多卡拆条**：说「示例猫吐了，示例狗拉稀了」→ 确认区应是**两张卡**（内容各异）→ 落 2 条不同。
- [ ] **A0'' 不该拆**：说「示例猫今天吐了，还称了体重4.2」（同一只一件事）→ **不拆**，单条编辑器，体重 4.2 + 描述呕吐在同一条。
- [ ] **A0''' 三只同事件**：「给示例猫示例狗示例龟都驱虫」→ 单卡预勾三只。
> LLM 拆得不对（该拆没拆 / 过度拆 / 预选不全）→ 记原话 + 实际结果，我调 prompt。

## Group A：Round 1 同事件批量（前端交互）
- [ ] A1 勾减：正常态多选，勾 2 只再取消 1 只 → 回单只态，**附件入口 + 养护输入行重新出现**。
- [ ] A2 批量隐藏：勾 >1 只 → 附件入口消失、底部显「已选 N 只 · 各存一条（批量暂不挂附件）」。
- [ ] A3 手动批量：点＋ → 结构化逐项 → 勾 3 只 + 类型「疫苗」+ 描述 → 确认 → toast「已归档 3 条」→ 时间线 3 条。
- [ ] A4 **双击守卫**：快速双击「确认归档 N 条」→ 只落 N 条**不翻倍**（review 修复点）。
- [ ] A5 体重批量：勾 2 只 + 填体重 + 类型体重 → 各自最新体重 / 体重曲线都更新。

## Group B：Round 2 一句话拆多条（前端交互）
- [ ] B1 删卡：说三件不同的事 → 出 3 张卡 → 点某张「删除」→ 剩 2 张 → 确认落 2 条。
- [ ] B2 逐卡编辑：multi 卡里改某条的宠物（点 chip）/ 类型 / 体重 / 描述 → 落库按改后的。
- [ ] B3 **双击守卫（multi）**：快速双击「确认归档 N 条」→ 不翻倍。
- [ ] B4 删到 1 张：多卡删到剩 1 张 → 仍可确认（落 1 条）。
- [ ] B5（选做，难造）部分失败：若能在 DevTools 制造「提交时某宠被另一端删」→ 失败卡显「没找到这只 · 请重选」、可重选、不空转死循环。

## Group C：单宠 + 不回归（确保两轮没搞坏老路径）
- [ ] C1 单只录入 + **真附件上传**：单只 + 挂图片/PDF → 确认 → 时间线该条 att_count 正确 → 详情页能看附件（真云存储 getTempFileURL）。
- [ ] C2 错别字：「示列猫今天拉稀」→ snap 到示例猫 或 确认卡点选。
- [ ] C3 建档：「新来只布偶叫示例橘，刚称2.1kg」→ 确认卡显「将建档」+ 选种类 → 落库 + 宠物页多一只。
- [ ] C4 单只全字段：就医 + 医院 + 费用 + 病程 tag → 时间线 / 病程视图正确。
- [ ] C5 药品入库：「买了盒驱虫药2支明年3月过期」→ 健康页药品库存。

## Group D：提醒（验 reminders 养护修复）
- [ ] D1 普通提醒：「下月15号给示例猫打疫苗」→ 健康页提醒，类型疫苗。

# PRD — PetsLog
<!-- 产品意图（产品类项目）。 -->

## 目标
做一款多宠家庭「像记账一样简单」的 AI 健康记录工具：一句话录入、AI 自动结构化、多宠独立档案、就医一键溯源。先满足开发者自身 + 身边多宠家庭朋友的真实使用，再温和商业化（一人公司 / 小而美）。

## 用户问题
- 多宠家庭高频记录健康信息（呕吐 / 拉稀 / 用药 / 疫苗 / 体重），现有工具录入繁琐、急救场景来不及。
- 多宠信息混杂，就医时回忆整理耗时、易漏关键病史，影响兽医沟通。
- 体重无法跟踪曲线；家庭药品（驱虫药等）库存与过期无管理。

## MVP 核心功能（5）
1. **多宠档案可视化**：首页宠物卡片（头像/名字/年龄/最新体重）；档案（品种/生日/绝育/过敏史/慢病）。物种 = 猫狗为主 + 兔 / 小宠 / 鸟 / 爬宠 / 鱼 / 其他（A 档统一记录，ADR-023）；每物种定制医疗（B 档）见 ROADMAP。
2. **极简快速录入**：底部中央「＋」一键进录入页，说一句即录；支持文字 + 输入法语音转文字；无多级跳转、无点选表单（录入入口从首页常驻输入条迁到全局录入页，见 ADR-010）。
3. **AI 智能解析（核心）**：从一句话提取并归档：宠物身份 / 时间 / 健康事件 / 用药 / 体重；可从就医描述中自动抓体重。
4. **健康时间线**：按时间生成单宠 / 全宠流水（症状/用药/疫苗/驱虫/体重/就医），记录可带就诊医院 / 费用 / 病程标签，支持按病程标签筛选；可截图分享给兽医。
5. **家庭药品库存**：药名 / 功效 / 剩余数量 / 过期日期；家庭共用台账，不绑单宠。

### MVP 增强（2026-06 已落地）
6. **宠物档案编辑**：品种 / 生日（自动算年龄）/ 绝育 / 过敏史 / 慢病可编辑；改名级联历史记录；可删档（病史保留在时间线）。
7. **体重曲线**：档案页按历史体重记录画折线，跟踪趋势。
8. **用药·疫苗·驱虫提醒**：一句话设提醒（含每周 / 每月 / 每年周期），「健康」tab 提醒分段，逾期 / 今天高亮，完成自动顺延，宠物页到期横幅。真推送（微信订阅消息）待后续，见 DECISIONS ADR-006。
9. **一键截图给兽医**：档案页一键生成含基础档案 + 近期记录的小结图，存相册 / 长按转发（含医疗免责声明）。
10. **家庭多租户 + 个人中心**：一个家庭多人协作记录（隔离键 openid → family，成员共享读写，邀请码加入），个人中心管理个人档案（昵称 / 微信头像）与家庭（切换 / 成员 / 转让 / 邀请）；家庭成员名 / 头像读时关联个人档案。见 ADR-008/009。
11. **底部导航重构**：底部 5 tab → 4 tab（宠物 / 时间线 / 健康 / 我的）+ 中央凸起「＋」全局录入键；提醒 + 药品合并「健康」分段页；录入迁到独立录入页。见 ADR-010。
12. **宠物档案卡（可分享图片 + 首页轮播门面）**：温暖治愈风的「毛孩子档案卡」海报图（头像 / 名 / 性别 ♂♀ / 物种品种 / 绝育 / 年龄 / 最新体重 / 陪伴天数 / 体重趋势曲线 / 简介），档案页一键生成存相册 / 长按转发，对外社交向（朋友圈 / 小红书）；萌宠 + 轻健康，绝不含费用 / 医院 / 病史 / 病程 / 用药（性别 / 绝育属低敏感基础档案信息，可上卡；病史 / 过敏不上，ADR-025）。**首页（宠物 tab）主视图即该卡的左右滑轮播**（一屏一宠、邻卡露边、末张「＋ 添加宠物」、点卡进详情），轮播与可分享图逐像素同款（共享渲染模块，所见即所分享）。见 ADR-021/022/025。
12. **字段扩展轮1（v0.3.1）**：records 加就诊医院 / 费用 / 病程标签（与事件类型双轴，时间线可按病程筛选）；event_type 增「驱虫」第 7 桶；pets 加到家日期 / 备注 / 头像（可上传真实照片）。费用解锁后续花费统计、病程标签解锁慢病管理。见 ADR-012/013。

### AI 解析字段（云函数 ↔ LLM 内部 JSON 契约）
目标输出强制 JSON，先判 `kind`（record / med_stock / reminder）分流：
- record（健康记录）：`pet`（匹配已有宠物名 / 未知则待确认）、`time`、`event_type`（症状/用药/疫苗/驱虫/体重/就医/养护/其它，8 桶，养护见 ADR-024）、`params`（养护参数对象，可空）、`weight`（可空）、`med`（可空）、`hospital`（就诊医院，可空）、`cost`（费用元，number\|null）、`tag`（病程标签，可空）、`desc`（干净事件描述，不含费用 / 医院 / 寒暄，给兽医小结拼接用）、`raw`（原文）；非健康内容返回 `valid=false`。
- med_stock（药品入库）：`med_name` / `med_effect` / `med_quantity` / `med_expire`。
- reminder（提醒）：`pet` / `rem_type`（用药·疫苗·驱虫·其它）/ `rem_title` / `rem_date` / `rem_repeat_days`（周期天数，0=一次性）。

## 成功指标
- AI 自然语言解析准确率 ≥ 90%。
- 单次健康记录 ≤ 10 秒完成，无学习成本。
- 内测：开发者自身 + 身边多宠家庭朋友稳定使用；中期目标日活 100+。

## UX 哲学
极简、高效、干净，「打开即录、自动整理」。减少操作步骤优先于功能丰富；AI 只做提取不做闲聊。

## 商业化（远期，非 MVP）
免费 + 会员订阅：免费版限 1–2 宠 / 每日 2 条 AI 记录 / 30 天留存；会员版无限宠物 + 不限次数 + 永久留存 + 医生病历总结 + 提醒 + 体重曲线 + 云同步。月付 8–12 元 / 年付 58–78 元（主推年付）。

# PetsLog 🐾

多宠家庭专属 **AI 健康记录工具**（微信小程序）。

> 像记账一样简单地记录宠物健康：在首页说一句话，AI 自动归档到对应宠物的健康时间线。

## 为什么做

家里养了一堆猫狗，看病时医生问病史答不上来；记事本和 Notion 都太重，宠物突发不适时连录入都来不及。市面产品要么表单繁琐、多宠体验差，要么聚焦 AI 问诊、忽视长期档案沉淀且有医疗合规风险。PetsLog 只做一件事：**让多宠家庭快速记录、清晰溯源、简单管理**。

## 核心体验

说一句「花轮今天吐了，体重 4.2kg」，AI 自动提取 **宠物身份 / 时间 / 健康事件 / 用药 / 体重**，归档到对应宠物的时间线。无需选宠物、选日期、填表单。

## MVP 功能

1. **多宠档案**：首页宠物卡片（头像 / 名字 / 年龄 / 最新体重）
2. **极简录入**：首页底部输入框，文字 + 语音，打开即录
3. **AI 智能解析**：自然语言 → 结构化字段，自动归档
4. **健康时间线**：单宠 / 全宠流水，可截图分享给兽医
5. **家庭药品库存**：药名 / 功效 / 数量 / 过期管理

## 技术栈

| 层 | 选型 |
|---|---|
| 前端 | uni-app（一套代码，目标端先微信小程序）|
| 后端 | 微信云开发（Serverless：云函数 + 云数据库 + 云存储）|
| AI | 自建 OpenAI 兼容 LLM 网关 → 文本模型（自然语言 → 强制 JSON）|

设计决策与架构详见 [`AIREADME/`](./AIREADME/)（ARCHITECTURE / DECISIONS / PRD）。

## 演进历程

PetsLog 是同一真实需求跨三个工具范式的演进：

- **v1**（2025.09）Cursor + uni-app + uniCloud：4 小时 MVP，内测后下线
- **v2**（2026.01）OpenClaw 重构：系统学习单 / 多 Agent 协作的载体
- **v3**（2026.04 起，本仓库）自然语言录入 + AI 解析：砍掉填表式交互

## 边界

工具属性，**不做医疗诊断 / 处方 / 医疗建议**，不替代专业兽医。仅做健康数据的记录、整理与展示。
